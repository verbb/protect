# Protect

Shared spam and abuse protection for Craft plugins and modules that accept input from the public.

Protect is a toolkit for developers. If your plugin or site module lets visitors post something, such as a comment, a contact message, a review, a vote or a support request, Protect checks each attempt for the signs of spam and abuse and tells your code what it found. It gives you honeypots, minimum form times, replay protection, rate limits, Cloudflare Turnstile, reCAPTCHA v3, hCaptcha and Friendly Captcha challenges, and Akismet, CleanTalk and OOPSpam spam classification behind one consistent API, so you don't build them again for every form. Your code still decides what happens next, whether that's saving, refusing, slowing someone down or holding a message for review.

Site owners don't install Protect themselves. It arrives as a dependency of a plugin that uses it, and that plugin provides its own settings.
